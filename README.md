## 👋 About me

I'm a developer based in Tunis. I build web applications with Python and Django, and I add AI where it brings real value: document analysis, AI agents, RAG pipelines and process automation.

I started in biology, moved into data analysis, then full-stack development. This path taught me one simple rule: understand the data first, then write the code.

Today I work on three things:

- **Building** AI products and web platforms, from the database to deployment
- **Delivering** client projects through my remote digital agency, Agencetek
- **Teaching** Python, data and AI to beginner developers and teams
